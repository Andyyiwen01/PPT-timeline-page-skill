# image_gen Prompt 配方

给 `image_gen` 拼装 prompt 的固定骨架。照这个结构填，不要漏段。

## Prompt 骨架

按顺序写，每一段一句话到三句话，不要写成长文：

```
一张 16:9 横版 PPT 单页，高智感手绘汇报风时间轴信息图，香槟米色系。
整体配色：[从 design-spec.md 选一组，写清楚底色+主色+点缀色，全部在奶油/米白/香槟金/暖棕范围内]。
版式：[水平时间轴从左到右 / 垂直时间轴从上到下]，时间轴横贯画面中部，占主体视觉。
页眉左上角小字写：[整体时间范围，如"2015 — 2022"]，右上角写主标题：[如"李明的七年"]。

时间轴上从左到右依次排布以下节点（节点帽用主色实心圆）：
1. [位置：左端 1/6 处] — 时间标签"[2015.09]"，下方短文字"[入学浙大]"，旁边配插画：[浙大校门手绘线稿]
2. [位置：2/6 处] — 时间标签"[2017 夏]"，下方短文字"[阿里实习]"，旁边配插画：[咖啡杯+笔记本电脑手绘线稿]
3. ... 逐个列完 ...
最后一个节点在右端 5/6 处，留 1/6 边距。

所有文字使用中文，简体，不要出现乱码或伪文字。
整页字体不超过 3 种：主标题用优雅粗衬线，时间标签用粗无衬线，事件说明用常规无衬线；最小字号不小于 8 号字。
每个节点旁的小插画必须与事件语义对应，细腻手绘线稿 + 淡暖彩填充风格，线条纤细有手绘松弛感，无生硬黑描边、无重阴影、无高饱和色。
所有文字、插画、节点帽都在画布边界内，不裁切、不出格、不重叠。
背景带极轻微奶油纸纹理，干净暖白留白，高级手账汇报感。
```

## 拼装时的硬性要求

- **节点必须按推算后的时间顺序列**，从左到右（或从上到下）。
- **每个节点都要写三件套**：时间标签 + 事件短文字（≤14 字）+ 插画具体画什么。少一项模型就会自由发挥出无意义装饰。
- **主动声明"中文、不要乱码、不要伪文字"**——这是出图最常见的失败点。
- **主动声明"不裁切、不出格、不重叠"**。
- **配色组名 + 具体色感都写**，光写"香槟奶油"不够，要加"底色奶油米白，主条香槟金，点缀暖深棕"。

## 完整正例

### 正例 A：直线时间轴（默认）

输入材料是 SKILL.md 里"李明"那段经历（5 个节点），选配色组 1（香槟奶油），水平版式。

```
一张 16:9 横版 PPT 单页，高智感手绘汇报风时间轴信息图，香槟米色系，气质精致克制。
整体配色：奶油米白底色（#F5EFE3 感），香槟金色为主时间轴与重标题，暖深棕为点缀色（#6B5440 感），暖色系平涂加细腻手绘线条。
版式：一条细香槟金水平时间轴横贯画面中部，节点均匀分布，线条略带手绘松弛感。
页眉左上角小字写"2015 — 2022"，右上角主标题"李明的七年"，优雅粗衬线大字。

时间轴上从左到右共 5 个节点（暖深棕色实心圆节点帽）：
1. 最左 10% 处 — 时间标签"2015.09"，下方短文字"考入浙大计算机系"，插画：浙大校门细腻手绘线稿。
2. 左 30% 处 — 时间标签"2017 夏"，下方短文字"阿里暑期实习"，插画：咖啡杯+笔记本电脑手绘线稿，淡暖棕填色。
3. 中 50% 处 — 时间标签"2019 夏"，下方短文字"入职深圳初创"，插画：公文包+深圳平安大厦小剪影手绘线稿。
4. 右 70% 处 — 时间标签"2020 秋"，下方短文字"赴美攻读硕士"，插画：飞机+美国东海岸天际线小剪影手绘线稿。
5. 最右 90% 处 — 时间标签"2022 夏"，下方短文字"回国加入腾讯"，插画：腾讯滨海大厦简笔轮廓手绘线稿。

所有文字使用简体中文，不要出现乱码、伪文字或英文字符串。
整页字体不超过 3 种：主标题优雅粗衬线，时间标签粗无衬线，事件短文字常规无衬线；最小字号不小于 8 号。
每个小插画细腻手绘线稿 + 淡暖彩填充风格，与事件语义对应，线条纤细有手绘松弛感，无生硬黑描边、无重阴影、无高饱和色。
所有文字、插画、节点都在画布边界内，不裁切、不出格、不互相压盖。
背景带极轻微奶油纸纹理，干净暖白留白，高级手账汇报感。
```

### 正例 B：城市/地点托举式（非直线）

适用场景：简历、多城经历、用户说"不同城市做了不同的事""按城市要有层次感"。不要画一条贯穿水平主轴，改用起伏山丘底座托举卡片。

```
一张 16:9 横版 PPT 单页，高智感手绘汇报风信息图，香槟米色系，气质精致克制，像高级咨询手账内页。

【核心视觉：城市托举感，不是直线时间轴】
画面底部是一排从左到右起伏的暖棕色山丘/云朵状城市底座，像连绵小山脉托举着上方的事件卡片。每个城市底座上有该城市的地标建筑小剪影（细腻手绘线稿），底座中央写城市名。事件卡片（圆角小卡片，米白底+细暖棕边）"浮"在城市底座上方，用一条细暖棕虚线从卡片底部连到城市底座。底座之间用浅金色柔和曲线连接表示时间流动，但不要一条笔直的水平主轴。

【配色】奶油米白底色（#F5EFE3），香槟金（#C9A961）用于连接曲线和高亮，暖深棕（#6B5440）用于文字和底座描边。城市底座用同色系深浅区分：起步城市=浅燕麦色（#E8DCC4）、中间城市=暖驼/焦糖棕（#A67C52/#8B6B4A）、当前城市=深巧克力棕或香槟金高亮（#5C4A38/#C9A961）。禁止藏青、酒红、亮蓝、纯黑。

【页眉】左上角小字"[时间范围]"，右上角主标题"[主标题]"，优雅粗衬线大字，深巧克力棕色。

【从左到右 N 个城市底座，高度错落】
1. 最左「[城市1]」底座（[深浅色]山丘）：地标=[城市1地标线稿]。底座上方托举 [1-3] 张卡片：
   - 时间"[YYYY.MM]"，事件"[事件短文字]"，小插画=[对应插画]
2. 左二「[城市2]」底座：地标=[地标线稿]。托举卡片：...
...
最后一个「[当前城市]」底座最高最大，边框加粗香槟金高亮，托举当前/最重要的大卡片。

【文字】所有简体中文，真实可读，禁止假字乱码伪文字。字体不超过3种：主标题优雅粗衬线，时间标签粗无衬线，事件文字常规无衬线。最小字号不小于8号字。城市底座上的城市名用粗体白色字。
【质感】插画细腻手绘线稿+淡暖彩填充，线条纤细有手绘松弛感。背景带极轻微奶油纸纹理。所有元素在画布边界内，不裁切不出格不压盖。卡片之间、底座之间留有充足呼吸感。
```

**关键提醒**：
- 不要写"水平时间轴横贯画面中部"——那是直线版式的指令，会冲突。
- 明确写"不要一条笔直的水平主轴"。
- 同一城市出现多次（如"上海实习"和"上海创业"）时，底座分列，当前那个用香槟金高亮。

## 常见失败反例（不要这样写）

```
❌ "做一个时间轴 PPT，牛皮纸色，上面写李明的经历。"
→ 模型不知道画几个节点、每个节点写什么、配什么插画，会自由发挥成 generic 装饰图。

❌ "节点：入学、实习、工作、留学、回国。"
→ 没写时间标签，模型会自己编年份；没写插画，模型会画无关装饰。

❌ "配色：高级感、商务风、好看一点。"
→ 不给具体香槟米色配色组，模型八成出成灰蓝商务模板，不是高智感手绘汇报风。

❌ 漏掉"简体中文、不要乱码"。
→ 高概率出现一团假汉字或英文字符串。
```

## 调用参数

```
image_gen(
  model_version="seedream_5.0_flash",
  width=2048,
  height=1152,
  prompt=<上面拼好的整段>
)
```

## 返工策略

出图后按 SKILL.md 第 6 步清单核对。常见问题与对应返工加词：

- **出现乱码/伪汉字**：在 prompt 末尾再加一句"文字必须是真实可读的简体中文，禁止任何假字、乱码、占位符文字。"
- **插画变成无意义装饰**：把每个节点的插画描述再具体一档（不要写"职业相关图标"，要写"咖啡杯+笔记本电脑"）。
- **文字溢出画布**：加一句"所有元素收紧在画面中央 90% 安全区内，四周留 5% 边距。"
- **配色不对**：把色感描述再写具体一点，例如"底色是 #F5EFE3 奶油米白，主条是 #C9A961 香槟金，点缀是 #6B5440 暖深棕，不要用藏青、酒红、亮蓝、纯白，整体必须是暖香槟米色感。"
- **字体太多太杂**：加一句"全页只用一种衬线体和一种无衬线体，共两种，时间标签和事件说明用同一种无衬线体，仅靠字号和字重区分层级。"
