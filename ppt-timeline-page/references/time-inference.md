# 时间线推算规则

把原文里的模糊时间词，回溯成图上能画出来的确定年月（或确定季度/年份）。

1. 模糊时间词速查表
2. 常识时长表

## 1. 模糊时间词速查表

按出现形态归类。遇到就向前回溯最近一个锚点。

| 原文写法 | 推算动作 |
|---|---|
| 三个月后 / 半年后 / 一年后 / 两年后 | 锚点月 + 对应月数，跨年正常进位 |
| 次年 / 翌年 / 第二年 | 锚点年 + 1，月沿用原文给的季节/月份；没给月就保留"该年"粒度 |
| 当年夏天 / 同年秋天 | 锚点年 + 季节；夏=6–8 月，秋=9–11 月，冬=12–2 月，春=3–5 月 |
| 入职第二年 / 大三下学期 / 工作第三年 | 锚点是入学/入职年；"第 N 年"= 锚点年 + N - 1 |
| 毕业之后 / 毕业后不久 | 锚点是毕业季；本科毕业默认为 6 月，"不久"= 当年 7–9 月，图上写"毕业同年秋"即可 |
| 暑假里 / 寒假里 | 锚点是所在学年；暑假 = 7–8 月（约 2 个月，按 3 个月粗算也可），寒假 = 1–2 月 |
| Q1 / Q2 / Q3 / Q4 | Q1=1–3 月，Q2=4–6 月，Q3=7–9 月，Q4=10–12 月 |
| 月初 / 月底 | 月初 = 该月 1–10 日，月底 = 20 日之后；图上一般不画到日，只画到月 |
| 世纪初 / 上世纪末 | 粗粒度，图上只写年代（如"2000 年代初"） |
| 大一时 / 研二开学 / 工作头一年 | 用下面常识时长表反推绝对年 |

## 3. 推算工作流

对每条模糊时间词，按顺序做：

1. **找锚点**：从当前这条事件开始，往前扫原文，找最近一条带确定时间（具体年月、具体年份、或"在 X 大学读大二时"这种带学段的表述）的事件。
2. **换算锚点到绝对年月**：如果锚点本身是学段（如"大二"），先用常识时长表把它落到绝对年。例：原文说"他 2015 年考入浙大"，那"大二"就是 2016–2017 学年，大二下 = 2017 年春。
3. **叠加相对偏移**：在锚点上做加减。"6 个月后"就在锚点月 +6；"次年春天"就是锚点年 +1 的 3–5 月。
4. **落到图上粒度**：能精确到月就写"2019.03"，只能到季就写"2019 春"，只能到年就写"2019"。**不要为了好看硬编一个精确月**。
5. **单调校验**：所有节点排好后，从左到右扫一遍，时间必须严格不减；相等就合并成一个节点。

## 4. 完整推算示例

原文片段：

> "2015 年 9 月，李明进入浙大计算机系读本科。大二暑假，他在阿里实习了两个月。毕业之后，他加入了深圳的一家初创公司。工作一年后，他辞职去美国读硕士。两年后，他拿到了硕士学位，回国加入腾讯。"

逐步推：

| # | 原文表述 | 推算过程 | 图上标签 |
|---|---|---|---|
| 1 | 2015 年 9 月，进入浙大 | 锚点本身 | 2015.09 入学浙大 |
| 2 | 大二暑假在阿里实习 | 2015 入学 → 大二 = 2016–2017 学年 → 大二暑假 = 2017 年 7–8 月 | 2017 夏 阿里实习 |
| 3 | 毕业之后加入深圳初创 | 本科 4 年 → 2019 年 6 月毕业；"之后"= 2019 年夏 | 2019 夏 入职深圳初创 |
| 4 | 工作一年后辞职去美国读硕 | 2019 夏 + 12 个月 ≈ 2020 夏；秋季入学更合理，落到 2020 秋 | 2020 秋 赴美读硕 |
| 5 | 两年后拿硕士学位回国 | 硕士按 2 年专硕算 → 2022 夏毕业；"回国加入腾讯"= 2022 年夏 | 2022 夏 回国入职腾讯 |

最后校验：2015.09 → 2017 夏 → 2019 夏 → 2020 秋 → 2022 夏，单调递增 ✓。

## 5. 粒度降级规则

- 推到月这一层有歧义时（比如"毕业之后"没说具体几月），退到季节。
- 季节也有歧义时，退到年。
- 永远不要为了让图上"整齐"而编一个不存在的精确日期。图上允许同时出现"2019.03""2019 夏""2020"三种粒度混排。
- 如果某个事件原文完全没给时间线索，也推不出，**不要画上去**——时间线只放能定位的节点。
