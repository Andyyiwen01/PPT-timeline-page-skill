# 视觉设计规范

高智感手绘汇报风（香槟米色系）时间线页的硬性视觉规则。配色、版式、插画语义、字体都从这里查。

## 目录

1. 香槟米色配色组（直接选一组，不要跳出色系）
2. 节点数量 → 版式决策
3. 插画语义映射表（事件 / 地点 / 人物）
4. 字体与字号
5. 高智感手绘汇报风质感细节

---

## 1. 香槟米色配色组

从下面选一组，整页只用这一组。在 prompt 里要写清楚"底色 + 主色 + 点缀色"三件套。整体锁定在奶油 / 米白 / 香槟金 / 暖驼棕的暖色系内，**不要出现藏青、酒红、亮蓝等高饱和撞色**。

| 组名 | 底色 | 主色（时间轴/重标题） | 点缀色（小插画/强调） | 气质 |
|---|---|---|---|---|
| **香槟奶油（默认首选）** | 奶油米白（#F5EFE3 感，暖白偏米） | 香槟金 / 暖驼金（#C9A961 感） | 暖深棕（#6B5440 感） | 高智感汇报、个人成长、人物回顾 |
| **燕麦驼色** | 燕麦米色（#EDE4D3 感，比默认深一度） | 焦糖棕 / 暖驼（#A67C52 感） | 墨褐（#3E3228 感，用于重文字） | 沉稳学术、研究复盘、深度汇报 |
| **奶白浅金** | 本白奶油（#F8F4EC 感，接近纯白但暖） | 浅香槟金（#D4B87C 感，更柔和） | 灰褐（#8A7A66 感） | 轻盈简报、校园主题、青年成长 |
| **深棕香槟** | 浅牛皮纸米色（#E8DCC4 感） | 深巧克力棕（#5C4A38 感，做主轴和重标题） | 香槟金（#C9A961 感，做节点帽和强调） | 高端汇报、融资/上市里程碑 |

**选色原则**：
- 个人成长 / 人物经历 → 优先组 1（香槟奶油）或组 3（奶白浅金）。
- 公司里程碑 / 融资 / 产品发布 → 优先组 4（深棕香槟）。
- 学术汇报 / 研究复盘 / 沉稳主题 → 优先组 2（燕麦驼色）。
- 拿不准就用组 1，最安全、最百搭。

## 2. 版式决策：先选视觉隐喻，再选方向

**不要默认就是一条直线时间轴。** 先看内容的天然结构，再选版式隐喻。

### 2.1 直线时间轴（默认）

适用于事件按一条线推进、没有明显分组的场景（公司大事记、项目里程碑、新闻经过）。

| 节点数 | 走向 | 排布 | 备注 |
|---|---|---|---|
| ≤ 6 | 水平 | 节点均匀分布在一条横贯画面的粗轴上，左右留白 | 最经典汇报版式 |
| 7–10 | 水平 | 轴在画面中线，节点文字气泡**上下交错**（一上一下），避免叠轴 | 每个气泡里：时间标签在上、事件短文字在下、插画在气泡旁 |
| > 10 | 垂直 | 轴纵向贯穿画面左侧 1/3，节点卡片向右展开 | 卡片宽度要够放一行短文字 |
| 时间跨度 ≥ 10 年 | 水平 | 长跨度段用断点/波浪线断开，密集年份段放大展示 | 防止节点挤成一团 |

**不要**做斜轴、S 形轴、曲线轴——汇报场景下读者会读错顺序。

### 2.2 城市/地点托举式

适用于事件明显按城市/地点分组（简历、跨国经历、多城项目），分组数 3–6 个，且用户希望"看出城市层次/不同城市做了不同的事"。

**视觉结构**：
- 画面底部是一排从左到右起伏的山丘/云朵状底座，像连绵小山脉托举上方卡片。
- 每个底座上有该城市的地标建筑小剪影 + 城市名（粗体白字）。
- 事件卡片（圆角小卡片，米白底+细暖棕边）浮在底座上方，用一条细暖棕虚线从卡片底部连到底座，表示"在这座城市做了这些事"。
- 底座之间用浅金色柔和曲线连接表示时间流动，**不要画一条贯穿的水平主轴**。
- 同一城市出现多次（如"上海实习→上海创业"）时，底座分列；当前/最重要的那个底座最高最大，边框用香槟金加粗高亮。

**城市底座用同色系深浅区分**（都在香槟米色内，不跳出色系）：
- 按城市重要性/阶段定深浅：起步城市用浅燕麦色，中间城市用焦糖/暖驼，当前城市用深巧克力棕或香槟金高亮。
- 不要每个城市用完全不同的色相——保持暖色系内的深浅渐变，避免变成彩虹色编码。

### 2.3 阶段分区式

适用于事件按人生/项目阶段分组（"求学→实习→工作→创业"），用 3–5 个并排的圆角区块/拱门/台阶承载该阶段事件。区块大小随阶段重要性变化，最重要的当前阶段区块最大最亮。

## 3. 插画语义映射表

每个节点配一个 16:9 画布下约占画面 5–8% 的小插画。**插画必须能让读者不看文字就猜出事件类型**。统一为细腻手绘线稿 + 淡暖彩填充风格。

### 3.1 事件类型 → 插画

| 事件关键词 | 画什么（细腻手绘线稿 + 淡彩风格） |
|---|---|
| 入学 / 毕业 | 学位帽 + 卷轴文凭；入学画校门建筑 |
| 入职 / 换工作 | 公文包；或名片/胸牌 |
| 实习 | 咖啡杯 + 笔记本电脑 |
| 创业 / 公司成立 | 灯泡 + 小办公楼；或握手 |
| 融资（A/B/C 轮） | 带美元/人民币符号的钱袋；递增柱状图 |
| 产品发布 / 上线 | 礼盒打开；或火箭升空；或 Launch 旗帜 |
| 获奖 / 荣誉 | 奖杯；奖牌；月桂枝 |
| 搬迁 / 换城市 | 纸箱 + 搬家车；或地图定位钉 |
| 活动举办 / 发布会 | 麦克风 + 演讲台；或人群剪影 |
| 媒体报道 / 宣传 | 报纸版面；或扩音器 |
| 上市 / IPO | 钟（敲钟）；或股票上行曲线 |
| 离职 / 结业 | 挥手背影；或合上的书 |

### 3.2 地点关键词 → 插画

- **城市**：画该城市的 2–3 个标志性建筑剪影（广州=小蛮腰+五羊，上海=东方明珠+外滩，北京=天坛+国贸，西安=大雁塔+城墙，深圳=平安金融中心+市民中心）。**不要**用 generic 的"摩天楼群"冒充。
- **大学**：画校门简化线稿，或用"××大学"字样的圆形校徽贴画。
- **公司 / 园区**：画该公司的标志性建筑轮廓（如腾讯滨海大厦、阿里西溪园区），或其 Logo 化的色块。
- **社区 / 街道**：画低层居民楼 + 梧桐树这类可识别街景。
- **海外地点**：城市天际线剪影（硅谷=帕罗奥多低层硅谷风，纽约=曼哈顿摩天楼群，波士顿=红砖学院风）。

**拿不准某个具体城市画什么时**，就退一步：画一个"定位钉"图标 + 城市名字，不要硬编地标。

### 3.3 人物关键词 → 插画

- 不要画写实人像（会出怪脸），用**抽象身份符号**代替：
  - 导师 / 教授 = 黑板 + 眼镜；
  - CEO / 创始人 = 西装剪影 + 领带；
  - 记者 = 话筒 + 记者证；
  - 第一位客户 / 关键合伙人 = 握手剪影；
  - 团队成员 = 3 个简笔小人头像排成一排。
- 只有原文里反复出现、且对故事关键的人物才画；路人甲不画。

## 4. 字体与字号

整页字体 family ≤ 3 种（用优雅衬线体做标题的高智感，用干净无衬线体做事件说明，别混超过 3 种）。

| 元素 | 字号（2048×1152 画布） | 字重 |
|---|---|---|
| 主标题（如"李明的十年"） | 60–80 px | 粗 |
| 节点时间标签（如"2019.06"） | 36–48 px | 粗 |
| 节点事件短文字 | 22–28 px | 常规 |
| 角落备注 / 数据出处 | 18–22 px | 常规，**最小不能低于 18px**（对应 8 号字下限） |

**禁止**：整页堆 5 种以上不同字体；事件说明写成整段小作文（每节点 ≤ 14 个汉字）；把重要信息塞到 14px 以下。

## 5. 高智感手绘汇报风质感细节

- 时间轴本身是一条有宽度的手绘感细线（约 6–10 px，略带手绘笔触的松弛感，不要机械笔直的矢量线），在节点处用圆形香槟金 / 暖棕节点帽打断。
- 节点之间可以用短虚线或极细的暖棕色装饰线做间隔，但不要盖过信息。
- 角落留一个小字页眉，写时间范围（如"2015 — 2022"），呼应精致手账的版心感。
- 背景带极轻微的奶油纸纹理 / 水彩纸噪点，干净留白，不能干扰文字阅读。
- **不要**用拟物阴影、玻璃拟态、高饱和渐变、彩虹色——保持暖色系平涂 + 细腻手绘线条的高级汇报感。
- 插画统一为**细腻手绘线稿 + 淡彩填充**风格：线条纤细、有轻微手绘抖动感，填色薄而透，像高级笔记本里的手账插画，不要粗黑描边的卡通贴画。
