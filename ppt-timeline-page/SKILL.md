# PPT 时间线页面生成

把一段叙述性文字（人物自传、项目复盘、公司发展史、活动回顾、新闻事件经过等）加工成一张可直接放进 PPT 的 16:9 横版时间线单页图片。

## 硬性约束（不可违背）

- **画幅**：16:9 横版，调用 `image_gen` 时 `width=2048, height=1152`。
- **风格**：高智感手绘汇报风，香槟/米色/奶油暖色调。版式**不一定是一条直线时间轴**——根据内容特征选择最合适的视觉隐喻（直线时间轴 / 城市托举式 / 阶段分区式等），但"时间递进关系"必须是画面的隐形骨架。整体气质像高级咨询手账 / 质感笔记本内页：细腻手绘线条、暖白留白、克制优雅，不要粗犷涂鸦、不要高饱和撞色。
- **文字**：整页字体 family ≤ 4 种；屏幕换算后最小字号不得小于 8 号（约 2048 宽画布上对应 ≥ 28px）；单个事件标签文字 ≤ 14 个汉字，超出就拆成两行或改用插画。
- **插画**：每个关键节点配的插画/贴画必须承载语义（城市天际线=地点、公文包=入职、学位帽=毕业、礼盒=发布、扩音器=宣传……），禁止放无意义装饰图占位。能用图标/小插画表达的信息，不另写文字。
- **数据准确**：时间点推算必须可追溯到原文里的某个确定锚点，推算过程不写进给 image_gen 的 prompt，但要在工作草稿里自洽。

## 工作流

### 第 1 步：读材料，抽时间线原始事件

通读用户给的整段文字 / 文件，按出现顺序列出原始事件清单。每条先记下：
- 原文写的时间表述（可能是确定的"2019 年 3 月"，也可能是"大学二年级那年"、"拿到 offer 后三个月"）
- 事件一句话描述
- 涉及的地点 / 人物 / 事件类型（活动举办 / 个人经历 / 产品发布 / 融资 / 获奖 / 搬家 …）

**不要**在这一步就急着算日期，先把所有事件列全。

### 第 2 步：回溯推算模糊时间，落到确定年月

逐条处理时间表述。规则见 [`references/time-inference.md`](references/time-inference.md)，要点：

1. 遇到"半年后 / 三个月后 / 次年 / 毕业之后 / 入职第二年 / 暑假里"这类相对表述时，**向前回溯**最近一个带确定年月（或确定年份+学段）的锚点事件，在它基础上做加减法。
2. 回溯不到确定锚点时，用常识时长表（本科 4 年、硕士 2–3 年、小学 6 年、初中 3 年、高中 3 年、暑假约 3 个月、一个自然年 12 个月、Q1=1–3 月……）反推。
3. 推不出精确月就退到季度或半年，并在图上只标到那个粒度（例如只写"2019 夏"，不要硬编"2019 年 7 月"）。
4. 若材料本身跨越多年，优先按"年"为主要刻度，季度/月只在密集段细化。

推算完后，**时间轴上相邻两个节点的年份/月份必须严格单调递增**。发现倒序就回头检查第 2 步哪里算错了。

### 第 3 步：提炼三类关键词

- **事件关键词**：活动举办 / 入职 / 毕业 / 创业 / 融资 A 轮 / 产品发布 / 获奖 / 搬迁 / 离职 / 上市 …
- **地点关键词**：城市名、机构名（清华大学、腾讯大厦、xxx 社区、张江科技园…）
- **人物关键词**：只挑图上真正要画出来的人物身份（CEO、导师、记者、合伙人 Jenny、第一位客户…），不要把所有出现过的人名都堆上去。

这些关键词直接决定每个节点配什么插画，见 [`references/design-spec.md`](references/design-spec.md) 的"插画语义映射表"。

### 第 4 步：决定版式隐喻与配色

**先判断内容有没有天然的分组维度**（城市 / 公司 / 阶段 / 项目线 / 行业），再选版式：

- **默认直线时间轴**：事件是一条线推进、没有明显分组（如"公司发展大事记"）。按节点数选水平/垂直：
  - 节点数 ≤ 6：水平时间轴，节点均匀分布，左右留白。
  - 节点数 7–10：水平时间轴 + 上下交错排布文字气泡，避免文字压轴。
  - 节点数 > 10：改用垂直时间轴（纵向从上到下），或把同一年份合并成一个大节点。
- **城市/地点托举式**：事件明显按城市/地点分组（如简历、跨国经历、多城项目），且分组数在 3–6 个。底部用起伏的山丘/云朵状底座托举事件卡片，每个底座上放该城市的地标剪影+城市名，事件卡片浮在底座上方用虚线连接。时间顺序通过底座从左到右排列体现，不再画一条贯穿的水平主轴。同一城市出现多次（如"上海实习→上海创业"）时，底座分列并用高亮区分当前阶段。
- **阶段分区式**：事件按人生/项目阶段分组（如"求学→实习→工作→创业"），用 3–5 个并排的圆角区块/拱门/台阶承载该阶段的事件，区块大小随阶段重要性变化。
- 配色从 [`references/design-spec.md`](references/design-spec.md) 的香槟米色配色组里选一组，不要自由发挥跳出色系。

**判断口诀**：如果用户说"不同城市/阶段做了不同的事"、"按城市/阶段要有层次感"，就不要用直线时间轴，改用托举式或分区式；如果用户没特别说，默认直线时间轴最稳。

### 第 5 步：调用 image_gen 出图

按 [`references/prompt-recipe.md`](references/prompt-recipe.md) 里的配方拼装 prompt。**先根据第 4 步选的版式类型套对应骨架**：
- 直线时间轴 → 用"正例 A"骨架
- 城市/地点托举式 → 用"正例 B"骨架，明确写"不要一条笔直水平主轴"

prompt 里**必须**写清楚：
- 画幅比例与整体风格
- 选定的配色组（具体色名 + 大致色感，例如"奶油米白底色 + 香槟金 + 暖深棕点缀"）
- 版式隐喻（水平直线 / 垂直直线 / 城市托举 / 阶段分区）
- 按时间顺序逐个列出节点：`位置 → 时间标签 → 事件短标签 → 配什么插画`（托举式则按城市底座列）
- 明确写"文字使用中文，不要出现乱码或伪文字；整页不超过 3 种字体"
- 明确写"所有文字和插画都在画布边界内，不裁切、不出格"

调用参数：`model_version=seedream_5.0_flash`，`width=2048, height=1152`。

### 第 6 步：自检与返工

出图后按这个清单核对，任何一条不过就重新生成（在 prompt 里加重申）：

1. 时间轴上节点顺序和推算后的时间顺序一致，无倒序、无跳号。
2. 每个节点的插画和它的事件/地点/人物关键词对得上（地点节点画了对应城市/机构的抽象贴画，不是 generic 装饰）。
3. 文字没有溢出画布、没有压在时间轴上看不清、没有大面积乱码。
4. 整页文字总量克制：主时间标签 + 每节点 ≤ 1 行说明，多余信息已用插画代替。
5. 配色属于香槟米色暖色系（奶油/米白/香槟金/暖棕），不是灰蓝商务模板，也不是高饱和撞色。
6. 字体看起来是粗/中/细 2–3 档，没有出现 5 种以上不同字形。

## 交付

出图后，直接把图片展示给用户，并用 2–3 行字说明：推算时做了哪几处关键时间补全（让用户可以核对）、选了哪组配色。不要附带冗长的设计说明。
