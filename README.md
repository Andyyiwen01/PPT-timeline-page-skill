# PPT Timeline Page（PPT 时间线页面 Skill）

> 把一段人物经历、公司沿革、项目历程、事件回顾等文字材料，整理成一条逻辑连续的时间线，并直接生成一张 **16:9 横版高智感手绘汇报风**的 PPT 时间线页面图片。

适用于 AI 助手（如豆包等支持 Skill 机制的智能体）的时间线页面生成任务。用户给一段叙述性文字（人物自传 / 项目复盘 / 公司发展史 / 活动回顾 / 新闻事件经过），本 Skill 指导模型完成**模糊时间推算 → 关键词提炼 → 版式隐喻选择 → 插画映射 → 出图**的完整流程。

---

## ✨ 核心能力

| 能力 | 说明 |
|---|---|
| **回溯式时间推算** | 把「6 个月后」「次年春天」「大二暑假」等模糊时间词，回溯到最近锚点推算成确定年月（见 `references/time-inference.md`） |
| **常识时长补全** | 本科 4 年、硕士 2–3 年、暑假约 3 个月等，无锚点时反推 |
| **语义化手绘插画** | 事件/地点/人物关键词 → 有语义的小插画（学位帽=毕业、公文包=入职、城市天际线=地点…），禁止无意义装饰 |
| **香槟米色系版式** | 奶油米白底 + 香槟金主轴 + 暖深棕点缀，细腻手绘线条、克制留白，高智感汇报风 |
| **字数克制** | 能用插画表达就省文字，字体 ≤ 4 种、最小字号 ≥ 8 号 |

> ⚠️ 注意：本 Skill 的产物是**成图**。如果用户只要时间线文字整理而不要图，请直接做文本梳理，不要走出图流程。

## 🚀 安装

将整个 `ppt-timeline-page` 文件夹放入你的 Skill 根目录即可：

```bash
cp -r ppt-timeline-page ~/.doubao/agent_mode/workspace/.user_skills/
```

安装后重启会话，当用户请求「把这段经历做成时间线 PPT」「根据这份材料出一张时间轴页」时，Skill 会自动匹配生效。

## 🧭 使用流程

1. **抽事件**：通读材料，按出现顺序列出原始事件清单（时间表述 + 一句话描述 + 地点/人物/类型），暂不算日期。
2. **推时间**：按 `time-inference.md` 把模糊时间词回溯到最近锚点，推不出精确月就退到季度/年；相邻节点时间必须严格单调递增。
3. **提炼关键词**：事件关键词（入职/毕业/融资/发布…）、地点关键词（城市/机构）、人物关键词（只留图上要画的身份，如 CEO、导师）。
4. **选版式隐喻**：默认直线时间轴（≤6 节点水平 / 7–10 交错 / >10 垂直）；按城市分组用**托举式**；按人生/项目阶段分组用**阶段分区式**。
5. **出图**：按 `prompt-recipe.md` 套对应骨架，逐个列出节点「位置 → 时间标签 → 事件短标签 → 插画」；调用 `image_gen`，`width=2048, height=1152`（16:9），`model_version=seedream_5.0_flash`。
6. **自检返工**：按 SKILL.md 第 6 步的 6 条清单核对顺序、插画语义、文字边界、字数克制、配色、字体档数。

## ✅ 输出规格

- **画幅**：16:9 横版，2048 × 1152 px
- **风格**：高智感手绘汇报风（像高级咨询手账内页），细腻手绘线条、暖白留白，不要粗犷涂鸦、不要高饱和撞色、不要灰蓝商务模板
- **文字**：字体 family ≤ 4 种；最小 ≥ 8 号（2048 画布 ≥ 28px）；单节点标签 ≤ 14 汉字
- **插画**：细腻手绘线稿 + 淡暖彩填充，必须承载语义，禁止 generic 装饰

## ❓ 常见问题

**Q：为什么版式不一定是直线时间轴？**
直线轴适合单线推进的事件。若事件天然按城市或阶段分组，用托举式（山丘底座托卡片）或分区式（并排区块）更能体现层次——时间递进仍是隐形骨架。

**Q：模糊时间怎么标？**
能精确到月写「2019.03」，只能到季写「2019 春」，只能到年写「2019」。永远不要为了图上整齐硬编一个不存在的精确日期。

**Q：插画为什么必须「有语义」？**
时间轴上的读者靠插画快速识别事件类型。放无意义装饰图等于浪费节点，还会让画面显得廉价。
